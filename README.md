# Megan Elch · Data Portfolio

I'm a statistician and data scientist with a PhD in statistics, currently using single-cell proteomics to learn about Alzheimer's disease. Outside of work, I enjoy exploring datasets in other domains. Included is a collection of some of my favorite side projects.

---

## Projects

### H&M Customer Segmentation (Python)
RFM-based customer segmentation on H&M transaction data. Includes propensity score matching to estimate the effect of club membership on customer spend.

### Brazilian E-commerce Analysis (Python, SQL)
Exploratory analysis of the Olist dataset covering seller performance, category-level order value, repeat purchase behavior, and shipping patterns.

### AD Proteomics Explorer (R, Shiny)
Interactive Shiny app for exploring single-cell proteomics data across Alzheimer's disease progression (Braak staging). Includes volcano plots, cell-type comparisons, and patient-level abundance views.
[Launch app](https://megan-elko.shinyapps.io/ShinyAD/)

### H&M Customer Sales Analytics (Tableau)
Transaction volume, online vs. in-store sales, top product categories, and purchase patterns by age group.
[View on Tableau Public](https://public.tableau.com/views/HMCustomerSalesAnalytics/HMCustomerSalesandAnalytics?:language=en-US&:sid=&:redirect=auth&:display_count=n&:origin=viz_share_link)
